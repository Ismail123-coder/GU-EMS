GU-EMS
Galgotias University Event Management System

GU-EMS (Galgotias University Event Management System) is a software application designed to manage and organize university events efficiently. The system allows administrators to create and manage events while students can register and track event information in a structured and user-friendly interface.

Project Overview
The Galgotias University Event Management System (GU-EMS) helps simplify the process of organizing events within the university. It provides a centralized platform where administrators can manage events and students can easily view and register for them.
This system reduces manual work, improves event coordination, and ensures better communication between organizers and participants.

.

🚀 Features

📅 Event Creation & Management – Admin can create, update, and delete events

🧑‍🎓 Student Registration – Students can register for events online

📊 Event Monitoring – Track participants and event details

🔐 Admin Panel – Manage events and participants

💾 Database Storage – Secure storage of event and student information
